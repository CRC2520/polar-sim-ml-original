# Polar Dynamics of Consciousness – Reproducibility & Code Access

## Overview
This repository contains the full set of Python scripts and output folders used to run the simulations and experiments described in the paper:

> **"Polar Dynamics of Consciousness: A Framework for Human-Centered General Artificial Intelligence"**  
> Carlos Rodríguez Castro, 2025

The repository includes both the code to execute the experiments and the corresponding results directories for reproducibility.

---

## Repository Structure
```
results_p_mini_iacl/           # Results from Mini IACL scenario
results_p_mini_trauma_compare/ # Results comparing trauma simulation variations
results_p2_baseline/           # Results from Phase 2 baseline simulation
results_p6_stimulus/           # Results from Phase 6 stimulus mapping
results_p7_learnedM/           # Results from Phase 7 learned M scenario
results_p7_no_ethics/          # Results from Phase 7 without ethics regulation
results_p7_no_homeo/           # Results from Phase 7 without homeostasis

venv/                          # Python virtual environment (not included in repo)

engine_v1_locked.py            # Core simulation engine (locked version for reproducibility)
p_mini_iacl.py                 # Mini experiment – IACL scenario
p_mini_trauma.py               # Mini experiment – Trauma scenario
p2_baseline.py                 # Phase 2 – Baseline simulation
p6_stimulus_mapping.py         # Phase 6 – Stimulus mapping and response modeling
p7_learnedM.py                 # Phase 7 – Learned M scenario
report_utils.py                # Reporting and visualization utilities
```

## Getting Started

### Prerequisites
- Python 3.10+
- PyTorch
- NumPy
- Pandas
- Matplotlib

Install dependencies with:
```bash
pip install -r requirements.txt
```

---

## Running Simulations

### Example – Baseline Simulation (Phase 2)
```bash
python p2_baseline.py
```

### Example – Stimulus Mapping (Phase 6)
```bash
python p6_stimulus_mapping.py
```

### Example – Mini IACL Scenario
```bash
python p_mini_iacl.py
```

### Example – Trauma Simulation
```bash
python p_mini_trauma.py
```

### Example – Generate Reports
```bash
python report_utils.py
```

Results will be stored in their corresponding `results_*` folders.


---

## Results Folders Description

Each `results_*` folder contains the output data and visualizations generated by running the corresponding simulation script:

- **results_p_mini_iacl/** – Outputs from `p_mini_iacl.py`, representing the Mini IACL scenario simulations.
- **results_p_mini_trauma_compare/** – Outputs from `p_mini_trauma.py`, specifically comparing variations of trauma simulations.
- **results_p2_baseline/** – Outputs from `p2_baseline.py`, showing Phase 2 baseline performance metrics.
- **results_p6_stimulus/** – Outputs from `p6_stimulus_mapping.py`, including stimulus-response mapping results.
- **results_p7_learnedM/** – Outputs from `p7_learnedM.py`, showing Phase 7 Learned M scenario results.
- **results_p7_no_ethics/** – Outputs from Phase 7 simulation without ethical regulation enabled.
- **results_p7_no_homeo/** – Outputs from Phase 7 simulation without homeostasis control.

These folders are generated automatically when running the scripts and will store plots, metrics, and logs for each run.
