Frozen resolution:

`R36_FAIL`

R36 is the first campaign in this program to require D+C+R and the previously distributed higher-order capacities to coexist in one persistent agent, one continuous 1,760-step lifetime and one persistent model/memory state. Counterfactual lesions are evaluated from the same checkpoint; comparator agents are used only for donor-history transplantation.

## Main bottleneck

The limiting components are metacognition:
- calibration passes only **7/12**;
- functional confidence gating passes **8/12**.

Planning itself reaches the frozen **9/12** threshold. D+C+R, memory, own-history, source and time are substantially more robust.

The joint count falls to 4/12 because R36 forbids combining capacities across seeds.

## Retained adverse seed

Seed **2007010** is a broad retained failure: recurrent context, relation lesion, memory reentry, own-history transplant and source attribution all miss thresholds, while metacognitive functional gating also fails. It remains in the record.

## Development history

DEV1 showed anti-calibrated confidence. DEV2 learned confidence from local factual errors but remained weakly anti-calibrated. DEV3 restricted metacognitive adjudication to the learned non-shock operating regime; 3/4 development seeds then passed the complete conjunction. All development revisions occurred before confirmatory seeds were opened.

No confirmatory source, threshold or decision rule changed after the final freeze.

## Scientific interpretation

R36 establishes that one persistent implementation can express the full set of mechanisms in some seeds, and that the mandatory v1.1 core D+C+R is robust within this agent. It does **not** establish robust unified coexistence at the preregistered 9/12 level.

The failure is not evidence that memory, source/time attribution, own-history or planning are absent. It localizes the current integration gap to reliable metacognitive calibration/gating and, secondarily, joint robustness.

POLAR Core v1.1 therefore remains unchanged. R36 does not justify a new core revision.

A corrective R36-R1 should target metacognitive stabilization inside the same persistent agent without altering D+C+R, memory or planning tests.

## Boundaries

Same-program synthetic evidence only. R36 does not establish phenomenal consciousness, intrinsic selfhood, open-ended lifetime autonomy, independent replication or biological correspondence.
