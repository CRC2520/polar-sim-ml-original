This is a computational adversarial-comparison assay, not a consciousness test.

Three reference implementations receive the same local information and solve the same action/report/confidence task:

- GNW-like analogue: action, report and confidence all require workspace broadcast.
- HOT-like analogue: first-order action uses local representation; report and confidence require a higher-order/meta representation.

Frozen predicted lesion signatures (all intact action/report/confidence >=0.98):

- workspace action drop <=0.05; report drop >=0.40; confidence drop <=0.05
- meta action/report drop <=0.05; confidence drop >=0.40

GNW:
- workspace action/report/confidence drops each >=0.40
- meta action/report/confidence drops each <=0.05

HOT:
- workspace action/report/confidence drops each <=0.05
- meta action drop <=0.05; report/confidence drops each >=0.40

Each theory-specific complete signature must pass in >=9/12 seeds.

A PASS demonstrates discriminating computational predictions among these reference implementations. It does not establish that one theory is true, that the reference implementations exhaust the theories, or that any model is conscious.
