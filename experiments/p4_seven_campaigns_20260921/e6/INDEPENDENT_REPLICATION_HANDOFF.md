# E6 — Independent replication handoff

## Frozen scientific target

A third party should implement the current POLAR specification without importing this repository's executable implementation.

Required minimum targets:
1. Emergent reconsolidation: reproduce E1 task/generator and frozen endpoints on new seeds.
2. Polarity discovery: recover unlabeled causal antagonistic axes under independent mixing/generator code.
3. Cross-agent quotient: recover a 4D sufficient quotient, d3 failure, cross-agent alignment and intervention sensitivity.
4. Naturalistic organization: reproduce the standard-equation OOD comparisons.
5. Theory-discrimination: reproduce the preregistered lesion signatures using independently written reference architectures.

## Independence requirements

- separate implementation team or researcher;
- no reuse of this repository's experiment code;
- criteria frozen before the replicator observes its final outcomes;
- new seeds and, where possible, independently implemented generators;
- full negative/adverse outcomes retained;
- environment and dependency versions reported.

## Current internal proxy

A same-team clean-room proxy used alternative LSTM, MLP/Jacobian-SVD and PLS implementations and reproduced the central E1–E3 findings. This is useful robustness evidence but is explicitly not counted as independent replication.
