## R36-R1 adjustment

R36 estimated expected factual error from nearest historical states while ignoring action identity.

R36-R1 estimates action-conditional factual reliability from prior transitions in the same learned context using a normalized feature:

z = [state, 2 * action, predicted_next_state].

For a candidate action:
1. find nearest previous state-action-prediction features;
2. estimate local factual error from their realized residuals;
3. convert the expected error to an empirical reliability percentile;
4. compute both the myopic and two-step plan candidates;
5. use two-step planning only when:
   - the plan action has sufficient predicted reliability; and
   - the learned model predicts a positive two-step advantage.

No true environment matrix, future factual error, oracle action or confirmatory outcome is available to the gate.
