## P0-B — Adaptive relational necessity

Hidden context/relation labels are evaluator-only. PASS requires confirmatory medians:

- adaptive − frozen accuracy >= +0.08;

Adaptive-vs-always-on is descriptive and is **not** used to claim that binary gating itself is necessary; the confirmatory claim concerns adaptive relational reconfiguration versus frozen/no-cross organization.

A separate primary path is identical across organizations.

PASS requires confirmatory medians:
- integrated OOD metacontrol accuracy >= 0.92;
- |integrated − isomorphic generic| accuracy <= 0.002;
- integrated − factorized accuracy >= +0.030;
- integrated − factorized expected utility >= +0.008;
