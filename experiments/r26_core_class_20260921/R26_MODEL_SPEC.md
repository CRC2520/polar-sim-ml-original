# R26 — Minimal POLAR class specification (D+C+R+A)

Status: development freeze candidate, 2026-09-21.

This revision defines POLAR as an **organizational class**, not a privileged algorithm
and not a universal polarity ontology.

A realization belongs to the tested core class only when it operationalizes all four
contracts below in one acting system:

- **D — differentiated causal degrees of freedom.** Distinct variables/actions are
  preserved when collapsing them would remove causal information. Literal dual arrays
  are not required; any invertible or function-preserving representation is admissible.
- **C — causally active recurrent state.** Historical information can influence later
  action or report after the original observation is absent.
- **R — learnable/reidentifiable relations.** Cross-process relations are estimated from
  consequences and may be revised when the context-to-relation map changes. A fixed
  semantic catalogue is not required.
- **A — context-dependent access.** Information can remain causally active while not
  being currently available through the capacity-limited workspace/report route, then
  be promoted by a contextual query.

Additional rules:

1. **Polarity is contingent.** Antagonistic/complementary structure is a subtype of
   relational organization. If the generator does not contain it, the learner should
   not be required to invent it.
2. **Tension is diagnostic, not primitive.** No universal tension scalar is part of the
   class definition.
3. **Implementation invariance.** A generic isomorphic implementation that reconstructs
   the same effective organization belongs to the same functional class.
4. **Consciousness is external to the class definition.** E5/E7 remain a separate
   validation question; no consciousness level is required for class membership.
5. **No accumulation across checkpoints.** R26-A is specifically intended to place the
   D+C+R+A contracts in one controller and one trajectory. This does not retroactively
   combine prior campaign capabilities.

R26 contains three new assays:

- **R26-A Integrated Core Conjunction:** one long-horizon controller simultaneously
  exposes D, C, R and A, with targeted lesions and a coordinate-isomorphic control.
- **R26-B Contingent-Polarity Null:** a generator with diagonal, non-antagonistic
  structure tests whether relation/coactivation advantages disappear rather than being
  manufactured by the label POLAR.
- **R26-C External Standard-Dynamics Transfer:** the same adaptive relational control
  procedure is evaluated on canonical CartPole and Pendulum equations with parameter
  shifts, against dense generic, factorized, frozen/no-memory and privileged oracle-LQR
  references. These tasks were not designed from POLAR semantic pairs.

E6b independent replication and E7 prospective biological validation are **not**
internally closable by R26.
