# POLAR P3 — remaining internally testable gaps

P2-Critical closed four operational gaps but left several higher-order questions.

P3 addresses four gaps that can be tested internally without pretending to provide
external scientific independence:

1. **Prolonged autonomy / continual learning.**
   Eight long blocks revisit four task regimes. The agent receives noisy context cues,
   never a regime ID, and must retain and reuse action-consequence models when a regime
   returns after a long absence. The test measures recurrent-block transfer, final
   performance and retention relative to first acquisition.

2. **Autobiographical self / identity-specific own-history.**
   Each agent has a persistent but unobserved action-response profile. Only its own
   actions and factual rewards reveal that profile. The agent builds identity-specific
   autobiographical memory. Own memory is compared with stateless control and a memory
   transplant from a different agent under matched current observations.

3. **Endogenous goal-priority adaptation.**
   Three internal resources are observable, but no priority label is supplied. Goal
   weights are updated from the agent's own deficits and recent state trends. The test
   asks whether this endogenous prioritization improves viability and shock recovery
   relative to fixed priorities. This is not evidence of intrinsic moral values.

4. **Individual → population → ecology integration.**
   Multiple agents regulate extraction from a shared renewable resource. Individual
   restraint adapts to own state/resource dynamics; population transmission can copy
   successful restraint; ecology feeds back through resource regeneration. Selective
   lesions separate local adaptation from transmission.

External-team replication and neurobiological correspondence are not self-certifiable
and remain publication-stage external validation requirements.
