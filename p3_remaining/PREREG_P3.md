# POLAR P3 — frozen confirmatory protocol

Development seeds: 997001–997004.
Transparent stress panel: 997100–997119.
These 24 seeds are excluded from confirmation.

Confirmatory seeds: **998001–998012**.
Seed is the inferential unit. Each gap passes globally at **>=9/12** complete
seed-level conjunctions.

The scientific engine is frozen after the development/stress campaign. No
mechanism or threshold may change after confirmatory execution begins.

## A — prolonged autonomy / continual learning

The agent runs 4,800 closed-loop steps over eight 600-step blocks with regime
schedule 0,1,2,3,0,2,1,3. It observes noisy contextual cues, never a regime ID.
The persistent controller retains context-indexed factual action-consequence
models; the matched control deletes models on context changes.

Per-seed PASS:
- recurrence benefit over the reset comparator >=0.075 in the first 24 steps
  of revisited regimes;
- mean reward in the final two blocks >=0.90;
- mean revisited/first-visit reward retention >=0.98.

This is prolonged bounded continual autonomy, not open-ended lifetime autonomy.

## B — autobiographical self / identity-specific own-history

Each seed defines a hidden identity-specific 4x4 action capability matrix.
The same identity persists across acquisition and evaluation, while the
experience tape changes. Memory is learned only from the agent's own factual
actions/rewards. A donor memory is acquired from a complementary hidden
identity and transplanted under the recipient's same current observations.

Per-seed PASS:
- own-memory prediction MAE improvement over stateless >=0.05;
- foreign-memory transplant prediction damage >=0.20;
- foreign-memory transplant reward damage >=0.20.

This tests identity-specific autobiographical action history and transplant
sensitivity. It does not establish phenomenal or narrative subjectivity.

## C — endogenous goal-priority adaptation

Three resource variables are visible; no goal/priority label is provided.
The adaptive controller computes priorities from its own current deficits and
recent trends. Large survivable shocks target one resource at a time.
A neutral fixed comparator cycles resource/task actions without
state-dependent prioritization.

Per-seed PASS:
- adaptive alive fraction >=0.99;
- endogenous priority agrees with the currently most depleted resource >=0.90;
- proportional recovery-latency improvement over fixed comparator >=0.65;
- reduction in fraction of steps with any resource below 0.45 >=0.015.

Total task reward is descriptive only because resource prioritization trades
off against task actions. These are endogenous control priorities over
externally defined resources, not intrinsic moral values or self-created ethics.

## D — individual -> population -> ecology integration

Thirty agents extract from a shared renewable resource. A subset can adapt
restraint from local energy/resource feedback. Population transmission copies
higher-scoring restraint. Shared-resource dynamics feed back into later
individual outcomes. Full, no-local-adaptation and no-transmission conditions
use matched exogenous seeds.

Per-seed PASS:
- full final-window alive fraction >=0.99;
- resource gain full vs no-local >=0.02;
- restraint gain full vs no-local >=0.08;
- restraint shift full vs no-transmission >=0.15;
- resource effect full vs no-transmission >=0.05.

The transmission fitness explicitly includes the shared resource. This tests a
specified multilevel causal loop, not spontaneous social institutions or moral
coordination.

## External gaps

P3 cannot self-certify an independent scientific replication or a real
neurobiological correspondence. Those remain external validation requirements.
